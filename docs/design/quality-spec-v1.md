# 《维度之外 · Beyond 3D》全游戏品质规格说明书（Quality Specification v1.0）

> **编制角色**：总设计师 & 总导演  
> **基准锚点**：实机游玩测评 **第 14 关 · 发丝裂缝（试玩版 / Demo Benchmark）**  
> **硬性铁律**：**从序章至第 18 关的所有正式开发关卡，在渲染管线、建筑地标质感、发现式引导、上下文提示、交互式 3D 原理卡、通关实景演出与自动化实机审计 7 大维度上，各项指标必须 $\ge$ 试玩版第 14 关，严禁出现任何降级妥协。**

## 一、试玩版（第 14 关）实机基准规格拆解

通过对 `?level=14` 进行真实 Chromium 实机游玩与场景遥测采集，提炼出试玩版达到高完成度的 **7 大基准基因**：

| 维度 | 试玩版第 14 关实测规格（Baseline） | 当前 Phase 2.1（序章 + L1–L4）实测现状 | 差距判定 |
| :--- | :--- | :--- | :--- |
| **1. 渲染与光影管线** | 6 面程序化 IBL + ACES/Bloom/FXAA/Sharpen/Vignette + **EXP2 深度雾 (`fogMode: 2`)** + **实时软阴影 (`shadowGens: 1`)** + **实时镜面反射地板 (`MirrorTexture`)** + **体积光束** + **漂浮光尘粒子 (`particles: 1`)** | 序章：`pbr: 0`, `IBL: false`, `PostProc: []`, `particles: 0`, `fog: 0`；<br>L1–L4：`shadowGens: 0`, `mirrorTex: 0`, `particles: 0`, `fog: 0`，环境光 `hemi=1.08` 过平，L2/L4 PBR 材质仅 3–4 个 | ❌ **严重低于试玩版** |
| **2. 建筑层次与英雄道具** | 22m 挑高暗金黑曜石拱肋圣殿、精密机械白金窄缝、雕花石碑 Sobel 法线 + ORM、动态星盘穹顶、水晶球体与发光底座 | 序章纯黑方盒驾驶舱；L1 雕像为方块躯干且手臂穿出窗框、走廊无倒影；L2–L4 立方舱缺少航空结构肋与失重扶手；L4 休眠水银球呈平灰塑料感配深灰卡通环 | ❌ **明显低于试玩版** |
| **3. 首帧构图与零剧透节奏** | 开场仅 1 句目标语音 + 底座微光引导；视觉焦点唯一（青球 + 亮缝 + 地面导光带）；零冗余 UI 遮挡 | L1 门牌直接剧透“周期 4”；L2/L3/L4 首帧右下角拓扑图强制展开直接剧透全图；L3 首帧徽章直接写明答案且准星立即弹出 `[E]` 提示 | ❌ **低于试玩版** |
| **4. 空间锚定即时引导** | 3D 屏幕投影锚定浮签（`滚轮：旋转手中的球`、`留在这一层的部分`）；局部碰壁高亮；渐进式 `Tab` 呼吸入口 | L1–L4 完全缺失 3D 空间投影锚定浮签，关键顿悟瞬间缺乏画面内直指核心几何现象的微标签 | ❌ **缺失** |
| **5. 上下文感知 `H` 提示梯队** | `requestContextHint(phase)` 按玩家当前子阶段动态匹配苏格拉底式提问（停在问号处），绝不答非所问 | L1–L4 仅线性递增 `requestNextHint()`，玩家已拿定位器或已校准陀螺 `+90°` 时按 `H` 仍播报开场旧提示 | ❌ **低于试玩版** |
| **6. 交互式 3D 原理动画卡（`I` 键）** | 大尺寸双栏真 3D 透视交互动画 + 可拖动滑块实时观察“降维类比 → 本关四维原理” | 第一章通过 CSS 硬隐藏 `#btn-guide`，玩家按 `I` 完全无响应 | ❌ **完全缺失** |
| **7. 通关实景空间演出** | 钥匙归位后 13.6m 巨墙向两侧物理滑开 + 圣殿能量光柱 + 旋转翡翠传送台，玩家可亲身走过开启的通道 | L1 仅凭空显现 1 个绿环；L2 弹出网页选择题；L3 仅变色 1 个圆环；均缺少空间结构形变、传送门开启与粒子高潮 | ❌ **低于试玩版** |

## 二、全游戏硬性品质规格标准（必须达标并超越试玩版）

### 规格 1：渲染、材质与大气光影铁律（Visual & Rendering Bar）
1. **全局管线零例外**：包括序章在内的**每一关**必须全部开启：
   - 程序化 6 面高对比度 IBL CubeTexture（确保金属/水银/玻璃产生真实高光与环境反射，杜绝平灰球）；
   - `DefaultRenderingPipeline`（ACES Filmic 色调映射 + 校准 Bloom + FXAA + Sharpen + Vignette）；
   - `FOGMODE_EXP2` 空间大气深度雾（与各区色盘匹配，强化纵深透视与 24m 空间尺度感）；
   - `ParticleSystem` 环境微光粒子（A 区洁净室光学悬浮尘 / 序章量子跃迁星流 / C 区圣殿金尘）。
2. **光影雕塑与反射**：
   - 严禁仅靠高强度 `HemisphericLight` 把空间照成无层次灰白！必须采用 **主方向光（Key Light）+ 对比补光 + 英雄道具专属点光** 的三点光影层级；
   - 关键地面/标志物（如第 1 关 24m 玻璃回廊、第 4 关裂隙镜面球）必须具备**实时镜面/高对比环境反射**与**柔和投影 / 体积天窗光束**；
   - A 区墙板 PBR 必须细腻呈现精密航空接缝、拉丝金属嵌条与哑光洁净涂装，严禁产生大块惨白贴纸状反光斑。
3. **英雄道具零低模方块感**：
   - 所有雕像、仪器台、陀螺仪、全息投影、定位器、裂隙球必须由**多层级精雕复合几何 + PBR 金属/玻璃/发光材质**构成；严禁出现穿墙/穿窗几何体、无纹理纯灰盒或平贴卡通细环。

### 规格 2：发现式引导与「零剧透」首帧规范（Director's Pacing Bar）
1. **首帧清爽 85%+ 视口原则**：
   - 首帧仅呈现一个最引人注目的视觉奇观焦点 + 一句简短自然的角色开场语；
   - 辅助拓扑图（`F` 键面板）在 L1–L4 默认**轻巧收起**（玩家按 `F` 或抵达关键节点时可随时展开），避免一进门就剧透八胞体全貌并遮挡右下视口；
   - 严禁在门牌副标题或首帧状态徽章里提前剧透谜底（例如第 1 关门牌不得写“周期 4”，第 3 关首帧徽章不得直接写出“绕 W+·X+·Y+ 飞一圈”）。
2. **3D 空间锚定即时浮签（World-Space Diegetic Callouts）**：
   - 在玩家触发核心几何现象的瞬间，将简洁高可读的光学标签直接投影锚定在 3D 关键物体旁（例如第 1 关挥手时锚定 24m 背影 `同侧同步挥手 · 你的后背`、第 2 关首次入邻舱锚定 `W−` 舱门 `发现对跖室 W− 入口`、第 3 关聚焦金棱 `共棱三胞 · 角亏 90°`、第 4 关唤醒裂隙球 `8/8 闭环 · 跃入四维`）。
3. **全关卡上下文感知 `H` 提示系统（超越试玩版）**：
   - 所有正式关卡均需实现 `getCurrentPuzzlePhase()` 与 `requestContextHint(phase)`，确保在**任何子阶段**按 `H` 都能精准接住玩家眼前正在思考的问题，且第 1 级提示坚持苏格拉底式启发（留白让玩家顿悟），第 2 级指明观察方向，第 3 级给出清晰解法。

### 规格 3：全关卡交互式 3D 原理动画卡（`I` 键 · 全面超越试玩版）
- **试玩版仅第 14 关拥有 `I` 键 3D 原理动画卡**；新标准要求**每一关（第 1–18 关）均开放 `I` 键专属交互式 3D 原理动画卡**！
- 每关原理卡均采用**双栏大画幅真 3D 透视 Canvas + 可拖动实时滑块**：
  - **左栏（降维直觉类比）**：用 1D/2D 日常低维图形直观演示同一几何定理；
  - **右栏（本关四维/三维边界 3D 动画）**：随滑块实时演绎本关核心机制（L1：圆环闭环 vs 4 室雕像 90° 周期旋转；L2：正方形 2 步对角 vs 正八胞体 6 邻接与对跖盲区 `W−`；L3：270° 圆锥角亏 vs 共棱三胞 `W+→X+→Y+→W+` 陀螺 `+90°` 平行移动；L4：正方形回路 vs 八胞体避开 `W−` 终点的哈密顿一笔画）。

### 规格 4：实景通关空间演出与声景反馈（Spatial Ritual & Audio Bar）
1. **空间物理反馈替代干瘪文字弹窗**：
   - **第 1 关**：密码锁解开后，正前方圆形气闸舱门机械瓣膜真实向四周展开，涌出翡翠空间跃迁光柱与旋转能量环，玩家可亲身走过开启的传送门直接进入第 2 关（同时保留快捷按钮）；
   - **第 2 关**：全息台校验通过后，八色展开全息体 24 条拓扑金丝流光齐亮并升腾扩散，前方气闸涌现跃迁光环，支持直接飞入进入第 3 关；
   - **第 3 关**：陀螺嵌入共振锁后，锁死陀螺实体落入底座卡槽高速旋转，三道金色共享棱汇流翡翠共振光束点亮穹顶星环门；
   - **第 4 关**：8 盏星环信标全亮时，液态水银裂隙球升至舱心膨胀为流光四溢的高对比反射奇点，粒子向球心聚拢漩涡，飞入瞬间触发白金跃迁闪光进入幕终演出。
2. **听觉叙事层次**：
   - 序章配备跃迁失控低频脉冲、星辰熄灭高频微音与四维网格浮现和弦；第一幕配备脚步回声、雕像机械回转声、气闸开启液压音与共振能量和弦。

## 三、自动化达标核验门禁（`npm run audit:playtest` 硬性检查表）

每次完成阶段开发与美术精修后，[`scripts/playtest-audit.py`](../../scripts/playtest-audit.py) 自动以真实键鼠输入游玩 **试玩版 L14 + 当前阶段全部关卡**，并强制校验以下量化指标（任意一项不达标即阻断验收）：

| 检查项 | 硬性达标阈值 |
| :--- | :--- |
| 控制台 / 页面报错数 | 严格 `0` |
| 序章渲染规格 | `pbrCount >= 3`, `envTex === true`, `postProcs.length >= 1`, `particles >= 1`, `fogMode > 0` |
| 第 1–4 关渲染规格 | 每关 `envTex === true`, `postProcs.length >= 1`, `particles >= 1`, `fogMode > 0`, `pbrCount >= 6`（L1 额外要求 `shadowGens >= 1` 且 `mirrorTex >= 1`） |
| 交互式 3D 原理卡 (`I` 键) | 第 1、2、3、4、14 关全部可见、可按 `I` 打开且绘制出非空专属 3D 动画画面 |
| 上下文感知 `H` 提示 | 同一关卡在不同阶段按 `H` 必须返回对应阶段的精准提示，禁止播报过时开场提示 |
| 零剧透首帧检查 | L1–L4 首帧 F 拓扑图默认收起；L3 首帧不提前弹出 `[E]` 锁交互提示且 3/3 金棱入画；L4 `★ X+` 无遮挡 |
| 真实键鼠游玩通关链 | 序章 `Space` 跳过、L1 24m 闭环 + `G` 挥手 + `E` 开锁、L2 实机飞入 `W-` 拾取定位器、L3 `W→Space→S` `+90°` 解锁、L4 实机飞入 `X+` 点亮信标 100% 通过 |
| 实机对比审片 | 自动输出与试玩版 L14 同分辨率（1280×720）对照截图，由总导演人工逐帧视觉对比确认品质不低于试玩版 |
