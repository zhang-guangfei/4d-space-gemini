# 第一章：回廊空间站（当前实现）

以根 README 和 `apps/fps-demo/CHAPTER-1.md` 的当前版本段为准；后者较早修订段保留的是历史，不覆盖当前规则。

上篇：米白色柔光空间站，6×6×6 房间，前后可走、其余可观察。玩家追逐自像，观察左右雕像及三种不完整假说。阅读中央大厅、跑步机、球壳赤道三个模型即计数，不要求拖动行程。W+ 随后出现八胞体魔方模型，返回查看并点“打开舱门”。

下篇：六向通行、零重力、本体局部姿态，可向任意方向持续跨胞探索；八个房间各访问三次后，挑战从 W+ 一次不重复走完八室。成功后 W+ 镜面球开放；不把中心误称“第九个房间”。第二章为占位。

三种假说只解释部分观察；文案保留“假说描述、能解释什么、还无法解释什么”的游戏提示结构，不提前宣告答案。动画中的外部投影变形不代表居民实际尺寸变化。
